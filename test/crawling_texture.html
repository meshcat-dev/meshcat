You should see a conveyor belt glTF model and a plain box, both using the same belt texture (the box applies the texture in the opposite direction).

The box and glTF model are different in several critical ways:

  1. UV layout: the box and glTF model apply the texture in different directions.
  2. Texture scaling: the box has no texture scaling while the glTF has its own internal scaling.
  3. The geometries are different sizes (the glTF model has longer triangles).

Despite these differences, the textures should appear to be moving at the same speed (in the world frame). If they are moving at different speeds, it means an important contributor to the mapping of texture coordinates to world frame has been missed.

The controls below left allow you to adjust the crawl speed and axis, as well as the belt's heading. The arrow shows the crawl axis in the belt's own frame — rotating the heading demonstrates that the axis follows the geometry and the texture motion remains consistent relative to the *geometry*.
