Test: embedded image URL resolution

You should see a box with a red/white checkerboard texture.

The texture is referenced by a content-addressable-storage style URL (cas-v1/sha256abc123) that lives in a pre-populated asset dictionary. A DefaultLoadingManager.setURLModifier intercepts that key and returns the embedded data URL — exactly as a static-page export would do.

This page serves as a regression test on THREE.js behavior. Initially, introduced with a meshcat-local patch on THREE.js, the test will remain even after that patch gets upstreamed to THREE.js.

If the texture fails to load, that's indicative of a regression.

This file should successfully load in a browser with no server (i.e. via a file:// URL).
